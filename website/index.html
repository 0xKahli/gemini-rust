Dual Persistent Session

Zero repeated sign-ins. Securely caches tokens using native Windows Credential Manager (keyring) and DPAPI-encrypted user storage. Stay signed in across reboots.

✦

Auto Plan Quota Detection

Automatically queries account capabilities on login to distinguish Free Tier from ✦ Google AI Pro, unlocking Gemini 4 Argon frontier reasoning models.

🤖

Live Models Only (Zero 404s)

Dynamic model resolver queries Google API directly. Deprecated legacy versions (1.5, 2.0, 2.5) are automatically purged in favor of Gemini 4 (Argon/Hydrogen) and Gemini 3 Flash.

True token-by-token streaming built on Tokio async tasks. Tokens parse immediately with zero UI thread stutter, instant markdown rendering, and syntax highlighting.

Under The Hood

Rock-Solid Rust Architecture

UI & Rendering Engine

Built using egui / eframe, a modern immediate-mode GUI library. Compiles to native DirectX/WGPU commands, executing at 60 FPS without DOM or web engine layers.

Google OAuth 2.0 PKCE Security

Complies with RFC 7636. Ephemeral local HTTP server (127.0.0.1:40772) handles one-time authorization code exchange with CSRF protection, then shuts down immediately.

Encrypted Local Storage

Dual-layer session storage: credentials stored via Windows Credential Manager (CredReadW/CredWriteW) and Windows DPAPI encrypted JSON in %APPDATA%\gemini_client.

Async Networking Runtime

Powered by Tokio multi-threaded async runtime with Reqwest TLS/HTTP2. Streams chunks over crossbeam mpsc channels directly to UI state.
