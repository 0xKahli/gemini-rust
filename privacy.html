Privacy Policy

Last Updated & Effective: November 13, 2026

✦ Summary of Core Principles

  • Zero Telemetry & Tracking: Rusty Gemini collects absolutely zero telemetry, diagnostic logs, personal data, or usage metrics.
  • No Intermediary Servers: We do not operate proxy servers, user databases, or backends. All network requests travel directly from your device to Google's official endpoints.
  • Local-First Storage: Credentials and chat history reside exclusively on your local machine, secured via Windows Credential Manager and local user-level DPAPI encryption.
  • 100% Open Source: Every line of code is open source and auditable on GitHub.

1. Introduction

This Privacy Policy explains how Rusty Gemini ("the Application", "we", "our"), developed by Kahli (@0xKahli), handles information when you install, launch, or use the desktop client.

Rusty Gemini is an independent, native open-source Windows desktop application designed to provide a high-performance graphical interface for Google's Gemini models. Because privacy and user sovereignty are paramount, Rusty Gemini was engineered specifically to avoid external collection of user information.

2. Information We Do Not Collect

Unlike web applications or commercial SaaS products, Rusty Gemini does not collect, harvest, store, or transmit:

  • Personal identifying information (name, email address, phone number).
  • IP addresses, hardware UUIDs, or device telemetry.
  • Analytics, clickstream data, event logs, or error crash reports.
  • Your prompts, inputs, questions, code snippets, or attachment contents.
  • Your conversation histories or token consumption statistics.

No server operated by the application developer ever receives or observes your traffic.

3. Google OAuth 2.0 PKCE & Credential Handling

To interact with Gemini models using your Google account, Rusty Gemini implements standard OAuth 2.0 with Proof Key for Code Exchange (PKCE) conforming to RFC 7636:

  1. Authentication Flow: When signing in, the application directs your system default web browser to Google's official OAuth authorization endpoint (https://accounts.google.com/o/oauth2/v2/auth). You enter your Google credentials directly into Google's domain; Rusty Gemini never sees or handles your Google password.
  2. Ephemeral Local Callback: The authorization code is received locally on your PC via a temporary loopback web server listening on 127.0.0.1:40772/oauth2callback with CSRF state token verification. The loopback server terminates immediately once the exchange completes.
  3. Local Credential Storage: Retrieved access tokens and refresh tokens are stored strictly on your local machine across two layers:
    • Windows Credential Manager via native Win32 APIs (CredWriteW / CredReadW).
    • Encrypted JSON file located at %APPDATA%\gemini_client\auth.json, protected by Windows Data Protection API (DPAPI) and Windows file permission controls.
  4. Zero Remote Transmission: Your tokens are never transmitted to any third party other than Google's official token refresh endpoint (https://oauth2.googleapis.com/token).

4. Chat Logs & Local Storage

Your conversation history, system prompt settings, and custom instructions are persisted locally for your convenience:

  • Chat logs are saved to %APPDATA%\gemini_client\history.json on your personal drive.
  • Session settings are saved to %APPDATA%\gemini_client\settings.json.
  • No cloud syncing, remote backup, or external database is used.

5. Third-Party Services (Google APIs)

When you prompt Gemini, Rusty Gemini initiates an encrypted HTTPS connection (TLS 1.3 / HTTP/2) directly between your PC and Google Generative Language APIs:

  • generativelanguage.googleapis.com (model catalog and streaming inference)
  • accounts.google.com and oauth2.googleapis.com (authentication and token refresh)

Google's processing of your prompts and files is governed by Google's Privacy Policy (policies.google.com/privacy) and the terms applicable to your Google account or Google AI Pro tier.

6. User Control & Data Deletion

You have full and unilateral control over all data stored by Rusty Gemini at all times:

  • Sign Out: Opening the in-app Settings drawer and clicking "Sign Out" instantly deletes your session tokens from Windows Credential Manager and disk.
  • Clear History: Clicking "Clear current conversation" or deleting stored sessions wipes the corresponding local history.
  • Complete Uninstallation: Deleting the %APPDATA%\gemini_client folder removes 100% of residual files, leaving zero traces on your computer.

7. Security Practices

Rusty Gemini is developed in 100% memory-safe Rust with zero unsafe blocks in application logic. It enforces:

  • Cryptographically random CSRF verification on loopback authentication handlers.
  • Direct TLS encryption for all outbound network traffic.
  • Standalone execution without embedded web browsers, browser plugins, or remote script injection vectors.
